## ✅ Task 4 – House Price Prediction with Linear Regression

### Objective

Predict house prices using the California Housing Dataset with a Linear Regression model.

### Dataset

California Housing Dataset from **Scikit-Learn**

### Selected Features

- MedInc
- HouseAge
- AveRooms
- AveOccup

### Workflow

- Load Dataset
- Explore Dataset
- Select Features
- Train-Test Split
- Train Linear Regression Model
- Predict House Prices
- Evaluate Model
- Visualize Results

### Evaluation Metrics

- RMSE (Root Mean Squared Error)
- R² Score

### Results

| Metric | Value |
|---------|-------|
| RMSE | **0.8108** |
| R² Score | **0.4983** |

### Visualization

- Actual vs Predicted Scatter Plot

### Skills Learned

- Regression
- Linear Regression
- Feature Selection
- RMSE
- R² Score
- Data Visualization
